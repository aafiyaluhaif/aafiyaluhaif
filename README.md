## What I build

I build web applications, landing pages, service websites and backend APIs. My work focuses on clean component structure, sensible state management, responsive layouts and APIs that are easy for a frontend to consume.

## How I work

I like components that are small, reusable and easy to maintain. I reach for Redux when state is shared across many parts of an app, and for shadcn/ui when I want accessible, customizable components that I can adapt to a project's design instead of fighting a rigid library.

I write TypeScript to catch mistakes early, keep my commits focused, and deploy often so feedback arrives quickly.
